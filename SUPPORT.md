# Support

Use [GitHub Issues](https://github.com/Espaye/moneybird-mcp-server/issues) for reproducible
bugs and feature requests that contain no secrets or customer data.

For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).

This is a pre-1.0 community project. There is no guaranteed response time, uptime, data
recovery, bookkeeping correctness, or tax/accounting advice. Before asking for help:

1. reproduce with synthetic or redacted data;
2. include the package version, Python version, transport, credential mode, and capability mode;
3. include the failing command and sanitized traceback;
4. say whether the issue involves a read, cache, attachment, approval, or Moneybird write.

Never post Moneybird access/refresh tokens, MCP bearer tokens, OAuth client secrets, raw
invoices, contact data, audit logs, caches, or attachment contents.
